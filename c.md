# Программы, формальные языки и управление выполнением

## 1. Обработка программы

Обработка программы представляет собой многошаговый процесс.

Исходная программа проходит несколько отдельных стадий. Разные файлы могут обрабатываться независимо друг от друга, а затем объединяться.

В результате обработки нескольких файлов формируется исполнительный файл.

Общая схема:

```text
Исходные файлы
    ↓
Обработка отдельных файлов
    ↓
Объектные файлы / машинный код
    ↓
Объединение частей
    ↓
Исполнительный файл
```

При работе программы используются машинный код и дополнительная информация, связанная с объектами, объявленными в разных частях программы.

---

# 2. Формальные языки

Язык программирования является формальным языком.

Формальный язык задаётся правилами, позволяющими однозначно определить, какие конструкции являются допустимыми.

Для описания формального языка используются **грамматики**.

Грамматика задаёт структуру допустимых конструкций. Для её представления могут использоваться диаграммы.

Важно различать:

- исходный текст программы;
- отдельные символы;
- лексемы;
- синтаксические конструкции;
- структурное представление программы.

---

# 3. Символы и лексемы

Исходный текст состоит из последовательности символов.

Символами могут быть:

- буквы;
- цифры;
- специальные знаки.

Последовательности символов объединяются в более крупные элементы — **лексемы**.

Лексема — допустимое слово языка программирования, рассматриваемое как единый объект.

Например, отдельные символы исходного текста после обработки образуют лексемы, которыми затем оперирует синтаксический анализ.

Таким образом:

```text
символы → лексемы → синтаксические конструкции
```

После выделения лексем дальнейшая обработка работает уже не с каждым символом отдельно, а с полученными объектами.

---

# 4. Терминальные и нетерминальные символы

В грамматике различаются терминальные и нетерминальные символы.

**Терминальные символы** соответствуют элементам, из которых непосредственно строится текст языка.

**Нетерминальные символы** используются для описания внутренней структуры грамматики.

Из этих элементов с помощью правил грамматики строятся более сложные конструкции языка.

---

# 5. Синтаксический анализ

После выделения лексем выполняется **синтаксический анализ**.

Синтаксический анализ определяет структуру программы и устанавливает, как отдельные лексемы связаны между собой.

Результат можно представить в виде дерева, отражающего структуру программы.

Упрощённо:

```text
Исходный текст
      ↓
Последовательность символов
      ↓
Лексемы
      ↓
Синтаксический анализ
      ↓
Структура / дерево
```

Структурное представление позволяет рассматривать программу как совокупность связанных конструкций, а не как простой поток символов.

---

# 6. Объявления

В программе используются различные объявления.

Основные виды:

- объявление типа;
- объявление переменной;
- объявление функции.

Объявление задаёт соответствующую сущность и позволяет использовать её в дальнейшем в соответствии с правилами языка.

---

# 7. Функции

Функция должна быть объявлена для того, чтобы её можно было вызвать.

Объявление функции сообщает о существовании функции и о возможности её использования.

При работе с функциями важны:

- объявление;
- определение;
- вызов;
- адрес функции.

Определение содержит реализацию функции.

---

# 8. Директивы препроцессора

До основной обработки программы могут выполняться действия препроцессора.

В частности, существуют **директивы препроцессора**.

Они обрабатываются до дальнейших стадий обработки программы.

С препроцессором также связана обработка комментариев.

---

# 9. Операторы

Операторы задают действия и управление выполнением программы.

Выделяются различные виды операторов, среди которых:

- операторы вычислений;
- условные операторы;
- операторы циклов;
- оператор `switch`;
- `break`;
- `continue`;
- оператор присваивания.

Операторы образуют структуру выполняемой программы.

---

# 10. Условные конструкции

Условная конструкция позволяет выбирать дальнейший путь выполнения программы в зависимости от условия.

Условные операторы являются частью структурного управления программой.

При построении условных конструкций важно сохранять понятную структуру и единообразное оформление.

---

# 11. Циклы

Цикл предназначен для многократного выполнения некоторого участка программы.

Основными частями цикла являются:

- условие;
- тело цикла;
- переход к следующей итерации;
- завершение цикла.

Тело цикла выполняется до тех пор, пока выполняется соответствующее условие.

Циклы позволяют организовать повторяющиеся действия без необходимости многократно записывать одинаковый код.

---

# 12. `break`

Оператор `break` используется для выхода из соответствующей конструкции.

Он применяется, в частности, в:

- циклах;
- `switch`.

При наличии нескольких вложенных циклов `break` относится к самому внутреннему циклу.

Например:

```text
цикл 1
    цикл 2
        break
```

В данном случае `break` завершает `цикл 2`, а не `цикл 1`.

При вложенных конструкциях необходимо учитывать, к какому именно уровню относится оператор управления.

---

# 13. `continue`

`continue` связан с переходом к следующей итерации цикла.

При его выполнении оставшаяся часть текущей итерации не выполняется, после чего управление переходит к следующей итерации.

---

# 14. `switch` и `case`

Конструкция `switch` используется для выбора одного из нескольких вариантов.

Внутри неё располагаются варианты `case`.

Общая структура:

```text
switch
 ├── case
 ├── case
 ├── case
 └── ...
```

При использовании нескольких похожих `case` особенно важно следить за переходами между ними.

Неочевидное использование `break` может затруднить чтение программы и понимание того, где заканчивается выполнение одного варианта и начинается другой.

---

# 15. Вложенные конструкции

Конструкции языка могут находиться одна внутри другой.

Например:

```text
цикл
    условие
        цикл
            оператор
```

Чем больше уровней вложенности, тем важнее правильное оформление структуры.

При использовании управляющих операторов необходимо понимать, к какой вложенной конструкции они относятся.

Для `break` действует правило выхода из ближайшей соответствующей конструкции.

---

# 16. Область видимости

Объявленная переменная доступна не во всей программе автоматически.

Её область действия определяется местом объявления.

Если переменная объявлена внутри некоторой конструкции, после выхода из соответствующей области она может стать недоступной.

Например:

```text
начало внешней области

    объявление n

    цикл
        использование n

    использование n

конец внешней области
```

Если же переменная объявлена внутри цикла:

```text
цикл
    объявление n
    использование n

использование n
```

то за пределами соответствующей области её уже нельзя использовать.

Поэтому место объявления переменной необходимо выбирать с учётом того, где она потребуется.

---

# 17. Присваивание

Присваивание связывает переменную с некоторым значением.

Общая форма:

```text
переменная = значение
```

Присваивание является отдельной конструкцией языка.

Оно используется для изменения значения переменной и сохранения результата вычисления.

---

# 18. Структурное построение программы

Программа должна иметь понятную структуру.

Основные структурные элементы:

- последовательность операторов;
- условные конструкции;
- циклы;
- `switch`;
- вложенные блоки.

Структура должна позволять быстро определить:

- где начинается конструкция;
- где она заканчивается;
- какие операторы относятся к ней;
- куда передаётся управление.

---

# 19. Читаемость кода

Программы пишутся не только для компьютера, но и для человека.

Код может потребоваться прочитать:

- другому разработчику;
- человеку, который никогда раньше его не видел;
- разработчику, который будет изменять программу спустя длительное время.

Поэтому программа должна быть аккуратной и понятной.

Чем больше усилий требуется для чтения и понимания кода, тем сложнее его сопровождать и изменять.

### Основные принципы

- аккуратное оформление;
- единообразие;
- понятная структура;
- разумная вложенность;
- читаемые комментарии;
- отсутствие неоправданной сложности.

---

# 20. Комментарии

Комментарии должны быть аккуратными и читаемыми.

Их задача — помогать человеку понимать программу.

Плохо оформленный или чрезмерно сложный код увеличивает время, необходимое для понимания программы.

---

# 21. Структура как средство понимания

Хорошая структура программы позволяет видеть её логику.

При чтении кода важно быстро определить:

```text
какая конструкция началась
        ↓
какие операторы ей принадлежат
        ↓
какие конструкции находятся внутри
        ↓
где конструкция заканчивается
```

Особенно это важно для:

- вложенных циклов;
- условных операторов;
- `switch`;
- нескольких `case`;
- операторов `break` и `continue`.

---

# 22. Основные понятия

| Понятие | Смысл |
|---|---|
| **Формальный язык** | Язык с правилами, однозначно задающими допустимые конструкции |
| **Грамматика** | Набор правил для описания структуры языка |
| **Символ** | Элементарный элемент исходного текста |
| **Лексема** | Допустимый элемент языка, выделенный из последовательности символов |
| **Синтаксический анализ** | Анализ структуры последовательности лексем |
| **Терминальный символ** | Элемент, используемый при построении текста языка |
| **Нетерминальный символ** | Элемент внутренней структуры грамматики |
| **Объявление** | Задание сущности программы для последующего использования |
| **Функция** | Конструкция, которую можно объявить и вызвать |
| **Цикл** | Конструкция для повторного выполнения участка программы |
| **`break`** | Выход из соответствующей конструкции |
| **`continue`** | Переход к следующей итерации цикла |
| **`switch`** | Конструкция выбора варианта выполнения |
| **`case`** | Отдельный вариант внутри `switch` |
| **Область видимости** | Область, в которой доступно объявленное имя |
| **Присваивание** | Запись значения в переменную |

---

# 23. Главное

1. Программа проходит несколько стадий обработки.
2. Формальный язык задаётся правилами.
3. Грамматика описывает структуру допустимых конструкций.
4. Исходный текст состоит из символов.
5. Из символов выделяются лексемы.
6. Лексемы используются при синтаксическом анализе.
7. Синтаксическая структура может представляться в виде дерева.
8. В программе используются объявления переменных, типов и функций.
9. Управление выполнением строится с помощью операторов, условий и циклов.
10. `break` завершает ближайшую соответствующую конструкцию.
11. `continue` переводит выполнение к следующей итерации цикла.
12. Область видимости зависит от места объявления.
13. Читаемость программы важна для её понимания и последующего изменения.
14. Код должен быть понятен человеку, который будет с ним работать.
